
# Árbol de Sakura Interactivo (Musical) - KMR

Una experiencia web frontend inmersiva e interactiva que simula un árbol de sakura floreciendo bajo la luz de la luna, con animación de pétalos flotantes y acompañamiento musical integrado.Desarrollado con HTML, CSS y JavaScript.

---

## Características Principales

- **Algoritmo de Generación de Árboles:** Estructura fractal programada en JavaScript para dibujar de manera natural las ramas y brotes de flores.
- **Sistema de Partículas (Pétalos):** Animación fluida de pétalos cayendo constantemente con efectos de viento simulados mediante trigonometría.
- **Interactividad por Clics:** Al hacer clic en cualquier parte de la pantalla, se despliega una ráfaga de pétalos animados.
- **Multimedia Integrada:** Reproducción de audio ambiental sincronizada con un botón de control flotante (estilo reproductor moderno).
- **Diseño Responsivo y Estético:** Interfaz oscura, elegante y optimizada con gradientes y efectos de cristal (`backdrop-filter`).

---

## Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando tecnologías web estándar sin dependencias externas pesadas:
- **HTML5:** Estructura semántica de la página y etiqueta.
- **CSS3:** Estilos avanzados, animaciones, keyframes y efectos visuales de alta gama.
- **JavaScript:** Lógica del canvas, programación orientada a objetos para los pétalos, recursividad para el árbol y gestión del reproductor de audio.
